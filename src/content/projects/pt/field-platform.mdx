## O Desafio

Agências governamentais, ONGs e equipas de campo nos nossos mercados faziam inspeções, inquéritos e registos em papel, ou em ferramentas de inquérito para consumidores que pressupõem uma ligação que raramente existe numa visita de campo rural. Cada novo caso de uso significava construir — ou reconstruir — o mesmo problema de captura de dados offline do zero.

## O Que Construímos

A Plataforma de Campo é a nossa plataforma reutilizável e offline-first de recolha de dados: um sistema central único — autenticação, formulários, fluxo de trabalho, painel, relatórios, notificações, documentos, API — que diferentes soluções setoriais configuram em vez de reconstruir.

- Preenchimento de formulários totalmente offline: GPS, fotos, leituras de QR/código de barras e assinaturas capturadas no dispositivo
- Sincronização automática assim que há ligação, sem passo de exportação manual
- Fluxos de aprovação configuráveis que encaminham submissões para o revisor certo
- Painéis e relatórios em tempo real construídos a partir dos mesmos dados de campo, sem um passo separado de reintrodução

## Uma Plataforma, Diferentes Soluções

O mesmo sistema subjacente alimenta hoje [inspeções móveis](/solutions/mobile-inspection), [inspeções escolares](/solutions/school-inspection), [registo de agricultores](/solutions/farmer-registration), [registo de cidadãos](/solutions/citizen-registration), e [gestão de beneficiários de ONGs](/solutions/beneficiary-management). Cada solução personaliza os seus formulários, fluxo de trabalho e terminologia — nenhuma delas reconstrói a plataforma por baixo.

É a mesma filosofia por trás do [Landflix](/projects/landflix), a nossa plataforma imobiliária: construir o núcleo reutilizável uma vez, e deixar que cada vertical seja uma configuração dele em vez de um projeto separado.

## Resultados

A Plataforma de Campo permite-nos assumir um novo setor — um novo tipo de inspeção, um novo programa de registo — como um exercício de configuração medido em semanas, não uma construção do zero medida em meses.
